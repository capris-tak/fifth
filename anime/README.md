# ほしのとうだい (The Star Lighthouse)

A 60-second 2D animated short. Every frame, voice, note and sound is generated by code.

- `hoshi_no_toudai.mp4`: the finished film (1920x1080, 30fps, Japanese audio, plus a Japanese subtitle track you can turn on)
- Video: HTML5 Canvas drawn as a function of time (`src/`), captured with headless Chromium (`tools/render_all.sh`)
- Voices: VOICEVOX (冥鳴ひまり / 雨晴はう / No.7). Lip-sync is driven by mora-level timing (`tools/voices.py` → `src/timeline.js`)
- Music: original score synthesized with numpy (`tools/music.py`). Sound effects: `tools/sfx.py`. Mix: `tools/mix.py`
